 📖 ABOUT THIS PROJECT
--------------------------------------------------------------------------------

WTF.Console is a graphical wrapper around the Windows console / terminal. It
starts a hidden PowerShell child process and redirects its standard input,
output and error streams into its own WPF-based user interface, so that every
console-driven operation inside the WinTwin Fusion Framework can be fully
supervised, logged and controlled without ever showing a native console window.
