## About

To make it short: WinTwin.XUI is an exclusive library for the WinTwin.Fusion framework. It provides functions for both creating graphical interfaces and interacting with the UI.

## Note from the Developers

WinTwin.XUI is an integral part of the WinTwin.Fusion framework and was developed exclusively for it. During the development of WinTwin.XUI, it was not intended for the library to be used in any context other than the WinTwin.Fusion framework. While it is certainly possible that this functionality could work for other projects, any use outside of the WinTwin.Fusion framework is at your own risk.
